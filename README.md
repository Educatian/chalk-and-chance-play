# Chalk & Chance (Playable Web Build)

Playable HTML5 export of **Chalk & Chance**, a Pokemon-style teacher-simulation game for deliberate mental rehearsal of classroom decisions, built in Godot 4.6.3. This repository hosts the exported web build; the game source lives in [Educatian/chalk-and-chance](https://github.com/Educatian/chalk-and-chance).

**Status:** active (web build, updated alongside the main repo)

**Play:** https://educatian.github.io/chalk-and-chance-play/
